# slicer-profiles scaffold
Generated by `nix flake init -t github:cpederkoff/slicer-profiles-nix` - copy into an existing Home Manager config (e.g. `home/slicer-profiles/`), not used as a standalone flake

## How to run
### Wire it in
The flake must be in scope of this module. The simplest way is to reference `inputs` (threaded in via Home Manager's `extraSpecialArgs = { inherit inputs; }`, or `specialArgs` under a NixOS `home-manager.users.*`):
```nix
{ lib, inputs, ... }:
let
  slicer-profiles-nix = inputs.slicer-profiles-nix;
  slicerLib = slicer-profiles-nix.lib.mkProfileLib { inherit lib; };
in
{
  imports = [ slicer-profiles-nix.homeModules.default ];
  slicerProfiles = import ./slicer-profiles/profiles.nix { inherit lib slicerLib; };
}
```

### Add your own profiles
Rename or add to the example files in `printers/`, `filaments/`, and `prints/`; every `*.nix` file dropped in one of those directories becomes a profile automatically (`profiles.nix` scans them, so there's no list to maintain). Delete the examples you don't need.
